# 🚀 Release v1.0.0 (Stable MVP) — «Coffee & Food» (SmartCoffee Express)

Перша офіційна, стабільна версія вебзастосунку для автоматизації крафтових кав'ярень, успішно перевірена та підготовлена до релізу після фінального захисту.

## ✨ Основний функціонал:
* **Клієнтський каталог:** Зручний перегляд асортименту, вибір порцій (*Small, Medium, Large*) та кастомізація альтернативного молока.
* **Екран баристи (KDS):** Оновлення замовлень у реальному часі через polling, керування статусами (Прийнято $\rightarrow$ Готується $\rightarrow$ Готово $\rightarrow$ Видано) та смарт-таймер свіжості на 15 хвилин.
* **Адмін-панель:** Додавання нових позицій до меню та миттєве керування стоп-листом (`toggle-stock`).

## 🛠 Технічні особливості:
* **Архітектура:** Чітке розділення відповідальності (Separation of Concerns) із винесенням бізнес-логіки у сервісний шар (`orderService.js`).
* **Безпека:** Сувора валідація вхідних даних за допомогою бібліотеки `Joi` (`orderValidator.js`).
* **Стек:** Node.js, Express.js, React, Tailwind CSS.
