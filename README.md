# ☕ SmartCoffee Express — Back-end API & Real-Time Server

Серверна частина системи онлайн-замовлень та управління чергою для кав'ярні «SmartCoffee Express».

## 🚀 Технологічний стек
- **Node.js / Express.js** — REST API backend
- **Socket.io** — WebSockets real-time з'єднання (KDS панель бариста)
- **PostgreSQL / Redis** — зберігання даних та смарт-таймери
